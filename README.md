### WHAT IS THIS?
This is a continuation of one of my old unfinished clicker games. I've ported it over to Godot and added new features, and also changed the gameplay quite a lot.

This game now features roguelike gameplay in addition to the classic clicker game gameplay. I have added game rounds, which last 3 minutes each. After each round the player can pick a booster card which gives benefits but can also have disadvantages.

The old clicker game had a Minecraft theme, but I have removed most references because I don't want to get sued lol.
